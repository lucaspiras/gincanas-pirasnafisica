# Gincanas · Piras na Física

Site de **https://gincanas.pirasnafisica.com.br**: bolão da Copa 2026, gincana quiz e as gincanas futuras.

Site estático (HTML, CSS e JS puros, sem build), publicado pelo GitHub Pages a partir da raiz deste repositório. Ele contém **somente os arquivos publicados**; o banco de dados e o material de apoio não estão aqui.

Para ver localmente:

```bash
python -m http.server 8000
# http://localhost:8000
```

O site fala com o banco de produção: use contas de teste.
